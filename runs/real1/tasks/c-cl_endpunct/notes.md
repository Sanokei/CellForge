# cl_endpunct notes
Design: pure op wiring on ctx rows, generated by scripts/gen.py from the contract's own data tables (typed by architect).
- Per row r: letter_r = sum(row[10:36]); boundary_r = 1 - letter_r - apostrophe_r (all-zero row => boundary).
- A_L (L=1..7) = product of letter rows 7..8-L times boundary row 7-L: exact "anchored word of length L" indicator.
- Per table word (77 unique, len<=7): match = A_L * product of the letter one-hot entries (slice ops); times a [36]
  param vector holding its comma/period/excl values; all terms summed.
- q term: one cell (identity, W1 [36,1], b1 [36]) gives '!' = 1.3q-0.4, '?' = 1.2q-0.6, gated by row-7 letter.
- Words of 8+ letters in the tables ("surprise", "together") are skipped: spec says lookups need length<=7.
Params: 77 word vectors x 36 + 36 + 36 = 2844 numbers (79 param tensors, each <=40). Cells: 1 cell def (1 instance);
bundle has ~713 op nodes.
Cases passed: 14/14 (component-test).
Concerns: none on the contract; node count is large (~700 ops) but parameter-free. No corpus reading/counting used.
